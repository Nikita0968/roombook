# RoomBook — бронирование аудиторий

Веб-приложение для бронирования университетских аудиторий.

## 🗂️ Структура репозитория

- **`ui-lab-js/`** — актуальная версия (HTML + CSS + JS + Supabase). Это основной проект.
- **`roombook-flask/`** — ранняя версия на Flask (Python), оставлена для истории.

## 🔧 Стек актуальной версии

- **Frontend:** HTML, CSS, чистый JavaScript
- **Backend:** Supabase (PostgreSQL + Auth + RLS + триггеры + Realtime)
- **Графики:** Chart.js

## ✨ Функционал

- 🔐 Регистрация и вход (Supabase Auth)
- 🏛 Список аудиторий
- 📅 Создание брони с проверкой на пересечение
- 📊 Админ-панель со статистикой и графиками
- 📆 Календарь занятости (30-минутные слоты)
- 🔔 Уведомления в реальном времени (Realtime)
- 📜 История изменений статусов
- 👥 Просмотр зарегистрированных пользователей

## 🚀 Запуск

1. Открой папку `ui-lab-js/` в VS Code.
2. Запусти `index.html` через Live Server.
3. Ключи Supabase уже указаны в `app.js` (anon key — публичный, защищён RLS).
